# Harshil Bhardwaj — Portfolio

Personal portfolio site, built with plain HTML, CSS, and a bit of vanilla JS. No frameworks, no build step — open `index.html` and it just works.

🔗 **Live:** [harshil074.github.io/harshil-portfolio](https://harshil074.github.io/harshil-portfolio/#home)

## What's inside

- Hero with a live-typing terminal (real DevOps commands, animated)
- About / engineering approach — "manual-first, then IaC"
- Experience — current DevOps internship at Apptunix
- Tech stack — AWS, Docker, Kubernetes, Terraform, CI/CD, monitoring & security tools
- Featured projects — StudyOps, Project Nimbus, PipeLineOps
- Certifications
- Contact section (email, LinkedIn, GitHub, WhatsApp)

## Tech

HTML5 · CSS3 (Grid/Flexbox, custom properties) · Vanilla JS (IntersectionObserver for scroll reveals)

## Run locally

```bash
git clone https://github.com/Harshil074/harshil-portfolio.git
cd harshil-portfolio
open index.html   # or just double-click it
```

## Deploy

Pushed to `main` → served automatically via GitHub Pages.
