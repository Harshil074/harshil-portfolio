// PHILOSOPHY

Manual-first, then IaC

The engineering habit behind every project below — build it by hand once, understand every failure mode, then codify it so it never breaks the same way twice.

01 · BUILD

Provision manually

Click through the AWS console, wire up VPCs, ALBs, and services by hand to feel every dependency and failure point directly.

02 · UNDERSTAND

Break & debug it

Stress the setup, read the logs, fix the misconfigurations — real fluency comes from troubleshooting, not tutorials.

03 · CODIFY

Automate with Terraform

Once the architecture is proven, codify it into modular, reusable, version-controlled infrastructure as code.
